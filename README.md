# Predictive Journey Planner

An Information Technology final-year project for predicting future traffic and optimizing routes using AI.

## Stage 2: homepage and navbar

The project contains a responsive React + Vite JavaScript homepage with section navigation, a journey input preview, planned feature descriptions, and project information. Submitting the form shows a later-stage notice; it does not produce predictions. Backend, machine learning, data, maps, and route planning remain future work.

## Run on Windows

Install Node.js 24 LTS, which includes npm. Open PowerShell or Command Prompt in this project directory:

```sh
cd frontend
npm ci
npm run dev
```

Open the local address printed by Vite. Press Ctrl+C to stop the server.

To check the production build and code quality, run these commands from `frontend/`:

```sh
npm run build
npm run lint
```

`npm run preview` serves the production build locally after building.

## Folders and configuration

| Path | Purpose |
| --- | --- |
| `frontend/` | The React application and its development tools. |
| `frontend/src/` | JavaScript components and styles; `main.jsx` starts React and `App.jsx` connects the navbar and homepage. |
| `frontend/src/components/Navbar.jsx` | Shared navigation with section links and active styling. |
| `frontend/src/pages/Home.jsx` | Homepage sections and the journey preview form. |
| `frontend/public/` | Reserved for static files served directly; currently empty. |
| `frontend/index.html` | The HTML entry page where React mounts. |
| `frontend/package.json` | Dependency list and commands for development, building, linting, and previewing. |
| `frontend/package-lock.json` | Records exact dependency versions so `npm ci` can reproduce installation. |
| `frontend/vite.config.js` | Configures Vite and its React plugin. |
| `frontend/.oxlintrc.json` | Rules for the template's JavaScript code checker, Oxlint. |
| `.gitignore`, `frontend/.gitignore` | Keep dependencies, build output, logs, and local settings out of Git. |
| `frontend/README.md` | Reference documentation supplied with the Vite template. |
| `frontend/node_modules/` | Installed dependencies, generated locally and ignored by Git. |
| `frontend/dist/` | Production files generated by the build and ignored by Git. |

The application uses JavaScript. React type definitions supplied by the template help editor suggestions; they do not make this a TypeScript project.

## JourneyIQ interface

The public interface uses the JourneyIQ brand. The React/Vite frontend preserves validated, session-only journey state and a Results view. React Leaflet renders predefined schematic Pune corridors; these are not verified road directions. No traffic predictions, durations, distances, delays, or arrival times are calculated. Backend and ML integration remain future work. Refreshing clears saved details.
